Команды, которые я использовал в проекте:
 Для создания локального репозитория использовал git init.

 Далее команды которыми я чаще всего пользовался.
1) git add src/(file_path) - добавление нового файла или класса java в гит, чтобы была возможность коммитить.
2) git commit -m "add command txt to project" src/command.txt на примере данного файла:
 я коммитил - прописывая комментарий и file_path
3) git push origin home_work_25  - пуш всех изменений в гит
4) git rm --cached <имя_файла>
   git commit -m "remove имя_файла from repository"
   git push origin homew_work_25  - данными командами я воспользовался чтобы удалить из репозитория в гите файлы .idea
